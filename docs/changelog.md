# Changelog

## [2025-01-27] - Добавлены страницы аутентификации

### Добавлено
- Страница входа `/login` с формой аутентификации
- Страница регистрации `/register` с формой создания аккаунта
- Полнофункциональный компонент `LoginForm` с валидацией
- Полнофункциональный компонент `RegisterForm` с валидацией
- Поддержка входа/регистрации через социальные сети (Google, Discord)
- Валидация форм с отображением ошибок
- Обработка состояний загрузки
- Ссылки между страницами входа и регистрации
- Ссылка на восстановление пароля

### Изменено
- Обновлена документация Project.md с новыми страницами

- Использованы Nuxt UI компоненты (UInput, UButton, UCheckbox)

- Добавлены TypeScript интерфейсы для форм
- Интегрированы цвета и стили из дизайн-системы
- Подготовлена структура для интеграции с API
