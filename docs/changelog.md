# Changelog

## [2025-01-27] - Исправлена ошибка с UNotifications

### Исправлено
- Удален устаревший компонент UNotifications из default.vue layout
- Создан app.vue с настройкой UApp и toaster для toast-уведомлений
- Обновлена документация Project.md с актуальной информацией о системе уведомлений

### Изменено
- Система уведомлений теперь использует useToast composable вместо UNotifications
- Toast-уведомления настраиваются через UApp с позицией bottom-right

## [2025-01-27] - Добавлены роуты на страницы аутентификации

### Добавлено
- Роуты на страницы логина и регистрации в Header.vue
- Ссылки между формами логина и регистрации
- Навигация в мобильном меню на страницы аутентификации

### Изменено
- Кнопки "Войти" и "Регистрация" в хедере теперь ведут на соответствующие страницы
- Добавлены ссылки "Зарегистрироваться" в форме логина
- Добавлены ссылки "Войти" в форме регистрации

## [2025-01-27] - Очистка проекта от неиспользуемых компонентов

### Удалено
- **FeedbackForm.vue** - неиспользуемый компонент формы обратной связи
- **Advantages.vue** - неиспользуемый компонент преимуществ
- **HowItWorks.vue** - неиспользуемый компонент "Как это работает"
- **Partners.vue** - неиспользуемый компонент партнеров
- **MobileMenu.vue** - неиспользуемый компонент мобильного меню (функционал в Header.vue)
- **UserMenu.vue** - неиспользуемый компонент меню пользователя
- **TournamentDetails.vue** - неиспользуемый компонент деталей турнира
- **TournamentSidebar.vue** - неиспользуемый компонент боковой панели турнира
- **AdaptiveImage.vue** - неиспользуемый компонент адаптивного изображения
- **Button.vue** - неиспользуемый кастомный компонент кнопки (заменен на UButton)
- **Input.vue** - неиспользуемый кастомный компонент поля ввода (заменен на UInput)
- **Modal.vue** - неиспользуемый компонент модального окна

### Изменено
- Обновлена документация Project.md с актуальным списком компонентов
- Очищена структура проекта от неиспользуемого кода

## [2025-01-27] - Добавлены страницы аутентификации

### Добавлено
- Страница входа `/login` с формой аутентификации
- Страница регистрации `/register` с формой создания аккаунта
- Полнофункциональный компонент `LoginForm` с валидацией

### Изменено
