# Tournaments Frontend Project

## 📋 Обзор проекта

**Tournaments Frontend** - это современное веб-приложение для организации и участия в киберспортивных турнирах, построенное на Nuxt 4 с использованием Vue 3 и TypeScript.

## 🎯 Основные возможности

### Для пользователей:
- **Просмотр турниров** - каталог активных и предстоящих турниров
- **Детальная информация** - подробные страницы турниров с сеткой, участниками, правилами
- **Профиль пользователя** - статистика, история участия, достижения
- **Регистрация на турниры** - простое участие в соревнованиях

### Для организаторов:
- **Создание турниров** - интуитивная форма с настройками
- **Управление турнирами** - контроль участников и результатов
- **Мониторинг активности** - отслеживание прогресса турниров

## 🏗️ Архитектура проекта

### Технологический стек:
- **Frontend Framework**: Nuxt 4
- **UI Library**: Vue 3 (Composition API)
- **UI Kit**: Nuxt UI 3.3.3
- **Styling**: Tailwind CSS 4.1.13
- **Language**: TypeScript 5.9.2
- **Package Manager**: npm

### Структура проекта:
```
app/
├── components/           # Переиспользуемые компоненты
│   ├── forms/           # Формы (логин, регистрация, обратная связь)
│   ├── home/            # Компоненты главной страницы
│   ├── layout/          # Компоненты макета (хедер, футер, меню)
│   ├── tournaments/     # Компоненты турниров
│   └── ui/              # Базовые UI компоненты
├── layouts/             # Макеты страниц
├── pages/               # Страницы приложения (file-based routing)
│   └── tournaments/     # Страницы турниров
├── assets/              # Статические ресурсы
└── public/              # Публичные файлы
```

## 📱 Страницы и маршруты

### Основные страницы:
- **`/`** - Главная страница с баннером и списком турниров
- **`/login`** - Страница входа в аккаунт
- **`/register`** - Страница регистрации нового пользователя
- **`/tournaments`** - Каталог всех турниров
- **`/tournaments/[id]`** - Детальная страница турнира
- **`/create-tournament`** - Создание нового турнира
- **`/profile`** - Профиль пользователя
- **`/about`** - О проекте
- **`/contacts`** - Контакты

### Компоненты страниц:

#### Главная страница (`/`)
- **MainBanner** - героический баннер с призывом к действию
- **TournamentsList** - фильтры и список турниров
- **Advantages** - преимущества платформы
- **HowItWorks** - как это работает
- **Partners** - партнёры

#### Страница входа (`/login`)
- **LoginForm** - форма входа с валидацией
- Поддержка входа через социальные сети (Google, Discord)
- Ссылка на восстановление пароля
- Переход на страницу регистрации

#### Страница регистрации (`/register`)
- **RegisterForm** - форма регистрации с валидацией
- Поля: имя пользователя, email, пароль, подтверждение пароля, команда
- Согласие с условиями использования
- Поддержка регистрации через социальные сети
- Переход на страницу входа

#### Страница турнира (`/tournaments/[id]`)
- **TournamentHeader** - заголовок с основной информацией
- **TournamentTabs** - навигация по разделам
- **TournamentOverview** - контент активной вкладки
- **TournamentBracket** - турнирная сетка

#### Создание турнира (`/create-tournament`)
- Форма с разделами:
  - Основная информация (название, описание, игра)
  - Расписание (дата, время)
  - Настройки (участники, формат)
  - Правила турнира
- Боковая панель с превью

#### Профиль пользователя (`/profile`)
- Статистика пользователя
- История турниров
- Достижения
- Настройки аккаунта


### Структура данных:

#### Tournament:
```typescript
interface Tournament {
  id: string
  title: string
  game: string
  image: string
  status: 'registration' | 'upcoming' | 'live' | 'completed'
  date: string
  time: string
  prizePool: string
  participants: number
  maxParticipants: number
  progress: number
  description: string
  rules: string
  format: string
}
```

#### User:
```typescript
interface User {
  id: string
  username: string
  avatar: string
  team: string
  registrationDate: string
  lastActivity: string
  stats: {
    tournaments: number
    wins: number
    top3: number
    earnings: string
  }
}
```
